# Lane Battle — прототип боя (ТЗ №01)

Рабочее имя, в интерфейс не выводится. Вертикальный срез: один бой, без единого
решения игрока во время боя — только выбор, кого спавнить, пока копится еда.

## Запуск

```
python3 -m http.server 8000
```

Затем открыть `http://localhost:8000` в браузере.

Сборки нет: исходники и есть артефакт. Ничего не собирается и не билдится.

## Файлы

- `index.html` — разметка сцены и оверлей (еда, скорость, карточки юнитов, попапы).
- `main.js` — весь игровой цикл: пулинг, автомат состояний юнита (MOVE/ATTACK/SIEGE),
  очередь по X, ИИ врага по расписанию, еда, конец боя, juice-эффекты.
- `dev.js` — панель отладки, скрыта по умолчанию, тоггл клавишей `D`.
- `balance.json` — все числа боя. В коде чисел нет.

## Управление

- Три карточки внизу — спавн юнитов A/B/C за еду. При нехватке еды карточка
  затемнена, но клик даёт короткую тряску (отрицательная реакция), а не молчание.
- Кнопка `×1/×2/×3` в углу — переключает скорость симуляции по кругу.
- `D` — показать/скрыть панель отладки (ползунки на каждое число, живая
  статистика, рестарт боя, копирование текущего `balance.json`).

## Границы

Это прототип «ДО»: никакого выбора игрока внутри самого боя (только кого
заспавнить). Мета-экранов, апгрейдов, сохранений, звука, площадок — нет, и не
должно появляться без отдельного решения основателя (см. ТЗ, раздел 8).
