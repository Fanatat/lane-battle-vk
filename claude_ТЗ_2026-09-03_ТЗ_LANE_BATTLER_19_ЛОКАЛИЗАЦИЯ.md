# ТЗ №19 — Lane Battler: реальная локализация RU/EN (п.2.14, повторный отказ)

Дата: 2026-09-03. Автор: продюсерская сессия ("game studio news documentation").
Сохранено исполнителем в свой worktree для истории — записать в основной
чекаут не удалось (харнес блокирует прямую запись background-сессий вне
воркт-ри в основной чекаут).

## Контекст

Основатель перезалил build3 (после ТЗ №18) — Яндекс ОТКЛОНИЛ повторно по
п.2.14, та же формулировка. Диагноз (сравнение с game3/color_sort, у
которого этой претензии не было): в game3 `main.js` вызывает
`setLanguage(Platform.getLang())`, которая реально переключает словарь
`I18N` (`i18n.js`, RU+EN) и применяет его ко всем `[data-i18n]`-элементам —
язык на экране ВИДИМО меняется. В game4 (ТЗ №18) `getLang()` вызывается,
но результат уходит только в `document.documentElement.lang` — невидимый
атрибут, текст остаётся русским.

ГИПОТЕЗА (не подтверждена Яндексом напрямую, но единственное объяснение
расхождения с рабочим прецедентом game3): п.2.14 требует РЕАЛЬНО ВИДИМУЮ
смену языка (RU+EN), не факт вызова SDK.

Основатель подтвердил: делать полноценный словарь.

## Задача

Прочитать `game3/color_sort/i18n.js` целиком ПЕРЕД началом (эталон, не
изобретать заново): `I18N={ru:{...},en:{...}}`, `currentLang`,
`setLanguage(lang)` (ru-семья `['ru','be','kk','uk','uz']`→ru, иначе en
если есть ключ, иначе en), `t(key)` с фолбэком на ru, `applyStrings()` по
`[data-i18n]`.

1. Завести `i18n.js` со ВСЕМИ видимыми игроку строками интерфейса (меню,
   кнопки пуск/пауза/скорость/полноэкранный/звук, экраны кампании
   глава/битва/трофеи, апгрейды, финал-событие, футер email) — жанр
   текстонезависим в бою, английский почти бесплатен. Не расширять
   контент, только перевести существующее.
2. Если текст рисуется кодом на Canvas — единая точка перевода `t(key)` в
   месте отрисовки, суть та же, форма подстановки по устройству рендера
   этой игры.
3. В main.js заменить `document.documentElement.lang = Platform.getLang();`
   на `setLanguage(Platform.getLang())`.
4. Приёмка ВИЗУАЛЬНАЯ: headless с locale=en-US, СКРИНШОТ с английским
   текстом на экране — не только атрибут lang. Прошлый раз формальная
   проверка атрибута прошла, реальная — нет.
5. Регрессия — полный tests/, 0 новых провалов.
6. Пересобрать билды, новые номера.
