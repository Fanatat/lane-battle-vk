# ТЗ №20 — Lane Battler: 3 бага живого QA + landscape-lock

Дата: 2026-09-03. Автор: продюсерская сессия ("game studio news documentation"),
задача от живого QA основателя. Сохранено исполнителем в свой worktree —
записать в основной чекаут не удалось (та же харнес-блокировка).

## Три воспроизводимых бага, приоритет реальный, чинить сейчас

1. Экран поражения: окно с сообщением + кнопка «начать битву» внизу. При
   большом масштабе страницы/маленьком разрешении кнопка уходит за пределы
   видимой области — физически недоступна пользователю. Нужен fix layout
   (скролл внутри окна или адаптивное сжатие, по аналогии с тем, как Color
   Sort чинил похожий класс бага в лэндскейпе — см. `docs/02_ЖУРНАЛ.txt`,
   запись про Color Sort п.1.10.1, если нужен референс приёма).
2. Нижняя плашка BUILD перекрывает кнопку первого юнита «БОЕЦ» — визуальное
   наложение, развести по слоям/позициям.
3. Все юниты (свои и вражеские) смотрят в одну и ту же сторону — должно
   быть визуально очевидно, кто на чьей стороне (минимум — разворот
   спрайта по стороне, зеркалирование рига).

## Landscape-lock (мобильная версия)

Требование: для мобильной версии — ограничить игру ТОЛЬКО альбомной
ориентацией (портрет делает игровое поле слишком коротким, это уже было
известно раньше, теперь явное требование основателя). Решить самостоятельно
разумный механизм (оверлей «поверните телефон» на портрете, или CSS-медиа-
запрос) — форму реализации не переспрашивать.

## Приёмка

Живой прогон/скриншоты для каждого из трёх багов до/после, регрессия
`tests/` 0 новых провалов, билды пересобраны, отчёт в `ВЫДАЧА/отчёты/`.
